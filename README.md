# موقع عيد ميلاد إيمان ❤️ | سنة سعيدة (sana-saida-i)

موقع ويب متكامل وفاخر للاحتفال بعيد ميلاد «إيمان» بتصميم رومانسي مميز باللغة العربية.

## محتويات المشروع:
1. **النسخة التفاعلية الفائقة (Live App)**: تطبيق متكامل متاح للتجربة الفورية.
2. **مجلد النشر على GitHub Pages (`sana-saida-i/`)**: ملفات HTML5 و CSS3 و Vanilla JS نقية جاهزة للنشر الفوري على GitHub Pages تحت الرابط:
   `https://bilaldahmani349-cell.github.io/sana-saida-i/`
3. **أرشيف التحميل المباشر (`sana-saida-i.zip`)**: ملف مضغوط جاهز للتنزيل بنقرة واحدة من واجهة الموقع أو من المجلد.
