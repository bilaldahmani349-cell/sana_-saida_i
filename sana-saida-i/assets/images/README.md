# مجلد الصور الشخصية - sana-saida-i / assets / images

مرحبًا بك! هذا المجلد مخصص للصور الخاصة بالاحتفال بعيد ميلاد «إيمان».

## الصور المتوفرة افتراضيًا:
- `romantic_cake.jpg`: صورة كعكة عيد الميلاد الرومانسية
- `romantic_roses.jpg`: باقة الورود الجميلة
- `gift_box.jpg`: صندوق الهدية
- `starlit_night.jpg`: ليلة الاحتفال تحت النجوم
- `love_envelope.jpg`: مظروف رسالة الحب

## كيف تضيف صورك الشخصية؟
1. انسخ صورك وضعها في هذا المجلد (`assets/images/`).
2. يمكنك تسميتها بأسماء واضحة، مثل:
   - `photo1.jpg`
   - `photo2.jpg`
   - `iman.jpg`
3. افتح لوحة التحكم (`admin.html`)، أو عدّل ملف `js/main.js`، وضع المسار النسبي:
   `assets/images/photo1.jpg`
4. الصيغ المدعومة: JPG، PNG، WEBP، GIF.
