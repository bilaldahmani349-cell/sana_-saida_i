# مجلد الموسيقى - sana-saida-i / assets / music

هذا المجلد مخصص لموسيقى الخلفية الرومانسية للاحتفال.

## ميزة المشغل الذكي:
الموقع مزود بمُولّد نغمات بيانو رومانسي تلقائي يعمل عبر متصفح الويب (Web Audio API) مباشرةً وبشكل نقي وهادئ حتى دون إضافة أي ملف MP3!

## كيف تضيف ملف موسيقى MP3 خاص بك؟
1. ضع ملف الأغنية أو الموسيقى في هذا المجلد باسم:
   `song.mp3` (أو أي اسم تفضله).
2. افتح صفحة لوحة التحكم (`admin.html`)، وفي حقل مسار الموسيقى اكتب:
   `assets/music/song.mp3`
3. احفظ التعديلات، وسيتم تشغيل ملفك المخصص فور الضغط على زر التشغيل.
4. ملاحظة: إذا كان الملف غير موجود أو تم حذفه، سيعود الموقع تلقائياً لعزف لحن البيانو الرومانسي دون ظهور أي أخطاء.
