## 🚀 طريقة رفع الملفات ونشر الموقع على GitHub Pages (خطوة بخطوة):

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. سجّل الدخول إلى حسابك على GitHub: `https://github.com/bilaldahmani349-cell`.
2. اضغط على زر **New Repository** (مستودع جديد).
3. سمِّ المستودع بالضبط: `sana-saida-i`.
4. اختر نوع المستودع: **Public** (عام).
5. اضغط **Create repository**.

### الخطوة 2: رفع الملفات إلى المستودع
#### الطريقة السهلة (عبر المتصفح مباشرة دون برامج):
1. افتح صفحة المستودع الجديد على GitHub.
2. اضغط على **Add file** ثم **Upload files**.
3. اسحب جميع ملفات هذا المجلد (`index.html`, `admin.html`, مجلد `css`, مجلد `js`, مجلد `assets`, وملف `.nojekyll`) وأفلتها في نافذة المتصفح.
4. **تأكد أن ملف `index.html` موجود مباشرة في جذر المستودع (وليس داخل مجلد فرعي آخر)**.
5. اضغط على زر **Commit changes**.

#### أو الطريقة البرمجية (عبر Git في الطرفية Terminal):
```bash
git init
git add .
git commit -m "إطلاق موقع عيد ميلاد إيمان ❤️"
git branch -M main
git remote add origin https://github.com/bilaldahmani349-cell/sana-saida-i.git
git push -u origin main
```

### الخطوة 3: تفعيل خدمة GitHub Pages
1. ادخل إلى صفحة المستودع على GitHub.
2. اضغط على تبويب **Settings** (الإعدادات) في الأعلى.
3. من القائمة الجانبية اليسرى، اضغط على **Pages**.
4. تحت خيار **Build and deployment**:
   - في خانة **Source**، اختر **Deploy from a branch**.
   - في خانة **Branch**، اختر فرع `main` والمجلد `/ (root)`.
   - اضغط على زر **Save**.
5. انتظر من 1 إلى 2 دقيقة، ثم حدّث الصفحة. سيظهر لك الرابط باللون الأخضر:
   👉 `https://bilaldahmani349-cell.github.io/sana-saida-i/`

## 🎂 مميزات الموقع التفاعلية:
1. **صفحة استقبال رومانسية**: تضم اسم إيمان بخطوط عربية فنية وتأثيرات ذهبية ووردية ساحرة.
2. **كعكة عيد ميلاد تفاعلية**: شموع واقعية متحركة تنطفئ عند النقر عليها بصوت لطيف وتصاعد دخان ثم بهرجة وقصاصات احتفالية عند إطفاء جميع الشموع!
3. **عداد تنازلي دقيق**: يحسب الأيام والساعات والدقائق والثواني المتبقية حتى حلول عيد الميلاد.
4. **مظروف رسالة الحب السرية**: مظروف ختم شمع أحمر ينفتح ليكشف عن رسالة حب عميقة ودافئة.
5. **صندوق المفاجأة والهدية**: صندوق ثلاثي الأبعاد يكشف عن هدية معنوية وقصيدة شعرية رومانسية.
6. **مشغل موسيقى ذكي**: يعمل بمولّد نغمات بيانو رومانسي مدمج (Web Audio API) دون الحاجة لملفات خارجية، مع دعم كامل لتشغيل ملفات MP3 مخصصة.
7. **معرض صور رومانسي**: مجهّز بصور جميلة مع إمكانية تكبير الصور واستبدالها بصورك الشخصية.
8. **صندوق الأمنيات التفاعلي**: إمكانية سحب أمنية جديدة أو إضافة أمنيات لصاحبة العيد.
9. **لوحة تحكم سهلة**: تمكّنك من تعديل الاسم، الرسائل، المواعيد، وروابط الصور والرمز السري (الرمز الافتراضي: `1234`).
